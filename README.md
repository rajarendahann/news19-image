## How it works

`main.py` (Python 3.13, standard library only) writes the repository's `entry.png`
(1024x1024) to `/output/entry.png`. It is deterministic: both runs write the same bytes.

Run locally:

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
